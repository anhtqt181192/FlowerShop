# Flower Shop Backend Design

Thiết kế hệ thống Shop Bán Hoa theo:

- Domain Driven Design (DDD)
- Clean Architecture
- CQRS Ready
- EF Core Code First
- Domain Events
- Aggregate Root Pattern

# Domain Event Flow

## Create Order

```text
Create Order
    |
    +--> OrderCreatedEvent
            |
            +--> Reserve Inventory
```

---

## Payment Success

```text
Payment Success
    |
    +--> Order.MarkPaid()
            |
            +--> OrderPaidEvent
                    |
                    +--> Inventory.Deduct()
```

---

## Cancel Order

```text
Cancel Order
    |
    +--> OrderCancelledEvent
            |
            +--> Inventory.Release()
```

# Inventory Rules

## Rule 1

Không cho phép đặt hàng vượt tồn kho.

```text
ActualQuantity >= OrderQuantity
```

---

## Rule 2

Tạo đơn sẽ Reserve tồn kho.

```text
Available = 100
Reserved  = 0

Order Qty = 5

=>

Available = 100
Reserved  = 5

Actual = 95
```

---

## Rule 3

Hủy đơn sẽ Release tồn kho.

```text
Available = 100
Reserved = 5

Cancel

Available = 100
Reserved = 0
```

---

## Rule 4

Thanh toán thành công mới Deduct tồn kho.

```text
Available = 100
Reserved = 5

Payment Success

Available = 95
Reserved = 0
```

# Target

Mục tiêu hệ thống:

- Không overselling.
- DDD Aggregate chuẩn.
- Có audit tồn kho.
- Hỗ trợ CQRS.
- Hỗ trợ Event Driven trong tương lai.
- Dễ mở rộng sang microservice.
- EF Core Code First.
- Clean Architecture.
